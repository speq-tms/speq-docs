## Rollout order

Merge each RC into `main` in this order, and only after every issue on the milestone is closed.
The order is a dependency chain, not a preference.

1. **speq-contracts** — schemas everything else validates against
2. **speq-cli** — runtime; must match the contracts above
3. **speq-examples** — acceptance gate; proves the cli against a real API
4. **speq-github-runner** — wraps a published cli
5. **speq-docs** — documents what actually shipped

> `homebrew-tap` must not be merged before the `speq-cli` release artifact exists.
> In `speq-cli`, merging a branch whose name starts with `v` into `main` triggers the release build.
