# Contributing to speq-docs

## Workflow

- Keep documents concise and executable.
- Prefer incremental updates over large rewrites.
- Cross-link related documents when adding new sections.

## Pull request checklist

- [ ] Index is updated if new document was added.
- [ ] Naming and terminology are consistent (`speq`, `.speq`, mode names).
- [ ] Changes include rationale and acceptance criteria where applicable.
